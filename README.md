🏖️ BeachTime

BeachTime est une application web qui permet de découvrir les meilleures plages de Nouvelle-Aquitaine en fonction des conditions météorologiques.

🎯 Objectif du projet

Aider les utilisateurs à déterminer si les conditions météo sont favorables pour aller à la plage, en consultant les prévisions météorologiques heure par heure.

✨ Fonctionnalités

Affichage des plages de Nouvelle-Aquitaine.

Consultation des prévisions météorologiques.

Affichage de la température et du risque de pluie selon l'heure.

Identification visuelle des conditions favorables à une sortie à la plage.

Filtrage des plages selon les critères disponibles.

🛠️ Technologies utilisées

Go : développement du serveur et du backend.

HTML : structure des pages.

CSS : mise en forme et design.

API météo : récupération des prévisions météorologiques.

🚀 Installation et lancement

Cloner le dépôt :

git clone URL_DU_DEPOT

Entrer dans le dossier :

cd BeachTime

Lancer le serveur Go :

go run .

Ouvrir dans le navigateur :

http://localhost:8080
